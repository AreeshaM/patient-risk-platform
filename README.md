# 🏥 AI-Powered Patient Risk Intelligence Platform

A end-to-end machine learning platform that predicts hospital readmission risk 
for diabetic patients with explainable AI (SHAP).

## 🔍 Problem Statement
Hospital readmissions cost billions annually. This platform helps doctors 
identify high-risk patients before discharge.

## 🛠️ Tech Stack
- **Data Analysis:** Python, Pandas, NumPy
- **ML Model:** XGBoost, Scikit-learn
- **Explainable AI:** SHAP
- **Dashboard:** Streamlit
- **API:** FastAPI

## 📊 Dataset
UCI Diabetes 130-US Hospitals dataset — 25,000+ patient records, 50 features
